# Pulse 3D

เว็บภาษาไทยสำหรับส่งไฟล์ขอประเมินงานพิมพ์ 3 มิติ

## ใช้งานได้
- รับ STL, 3MF, OBJ สูงสุด 50 MB ต่อคำขอ
- เลือก PLA, PETG, ABS, TPU (รายการตัวอย่าง ต้องยืนยันสต็อกจริง)
- ความหนาแน่น 5–100%, ลายด้านใน 4 แบบ, รอยต่อ 4 แบบ
- จำนวนชิ้น อีเมล หมายเหตุ และสรุปงาน
- API เก็บไฟล์และคำขอใน Cloudflare R2 โดยตรวจสิทธิ์ด้วย Sites identity

## ยังไม่เปิดรับลูกค้าทั่วไป
- เว็บไซต์เผยแพร่แบบส่วนตัวสำหรับเจ้าของ
- Google login ยังไม่เชื่อมต่อ เพราะยังไม่มี Google Client ID และต้องยืนยันวิธีรองรับ external identity ของ hosting ก่อน
- ปุ่ม Google ไม่จำลองการล็อกอินสำเร็จ
- ยังไม่มีหน้าหลังบ้านดูคำขอ การแจ้งเตือนร้าน การชำระเงิน หรือคำนวณราคาจาก slicer
- ตรวจนามสกุลและขนาดไฟล์ ยังไม่ตรวจความสมบูรณ์ของ mesh
- การส่งคำขอไม่ใช่การยืนยันราคา หรือสั่งผลิต

## ไฟล์หลัก
app/studio.tsx : หน้าเว็บและตัวเลือก
app/globals.css : รูปลักษณ์และขนาดหน้าจอ
app/api/orders/route.ts : รับไฟล์และบันทึกคำขอ
.openai/hosting.json : รหัสเว็บไซต์และ binding ของ R2

## สำหรับผู้ดูแลพัฒนา
ติดตั้ง Node.js ตาม package.json แล้วใช้ npm install และ npm run dev
ใช้ npm run build เพื่อสร้างรุ่นเผยแพร่
อย่าใส่รหัสผ่านหรือ client secret ลงใน source code
